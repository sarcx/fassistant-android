Install

1ProbeRun this first. It reports what this phone allows. 2FassistantThe watchdog itself, version 0.1.0.
The download will not install
  1. Android asks once whether to allow installs from your browser. Allow it.
  2. On some phones the switch is under Settings → Apps → Special access → Install unknown apps.

Send the probe results back

  1. Open Probe, tap Run the checks, then Copy results.
  2. Come back here, paste into the box, and send.

This goes straight to the laptop, not to the internet. Send one per phone.

Then set the watchdog up

  1. Open Fassistant and work down the Permissions list, tapping Fix on each row.
  2. Tap Manufacturer settings and work through that checklist.
  3. Tap Add apps and pick what to watch. Each row shows how well that app can be detected.
